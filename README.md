# Loop Lab

Browser-based loop auditioning: pick a sampled loop and hear it locked to your
drum loop, varispeed'd to the drum tempo, swapped in on the next bar.

See `CLAUDE.md` for the product brief, core model and build order.

## Dev

```sh
npm install
npm run dev          # http://localhost:5173
npm test             # engine unit tests (vitest)
npm run typecheck
npm run build
```

## Dev loops (phase 1)

`public/dev/` holds three placeholder WAVs generated by `npm run gen:dev-wavs`.
Overwrite them with real recordings and keep `src/lib/devLoops.ts` (bpm, bars)
in sync. Files should be trimmed exactly to `bars × 240 / bpm` seconds; if they
are not, the engine trusts bpm + bars and sets `loopEnd` accordingly.

## Layout

```
src/engine/    pure TypeScript audio engine (no React)
src/hooks/     useEngine() — the only React ↔ engine bridge
src/lib/       data (dev loops now, Supabase later)
src/components/ UI
```
